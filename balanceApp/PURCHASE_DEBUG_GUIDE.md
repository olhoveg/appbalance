# Руководство по диагностике проблем с покупками

## 🔍 Проблема: Покупка произошла, но урок не разблокировался

### Шаги диагностики:

## 1. Проверьте логи сервера (Backend)
```
📨 Webhook received: {...}
🎉 Payment succeeded webhook: {...}
💾 Creating purchase in Firebase: {...}
✅ Purchase saved to Firebase via webhook: {payment_id}
```

**Если этих логов нет:**
- Webhook не настроен в YooKassa
- Сервер недоступен
- Ошибка в webhook обработчике

## 2. Проверьте Firebase Database
Перейдите в Firebase Console → Realtime Database → `videoLessonPurchases/{userPhone}`

**Должна быть запись:**
```json
{
  "userId": "79034530417",
  "videoLessonId": "lesson_6",
  "price": 1000,
  "paymentMethod": "YooKassa",
  "transactionId": "30354aa8-000f-5000-b000-1353488a5296",
  "purchaseDate": "2025-01-20T10:30:00.000Z",
  "status": "completed",
  "webhookProcessed": true
}
```

## 3. Проверьте логи iOS приложения
```
🔄 Приложение стало активным, проверяем статус платежа: {payment_id}
🔍 Проверка покупки в Firebase: найдена
✅ Покупка уже существует в Firebase (обработана webhook), отправляем уведомление об успехе
🔄 Обновляем статусы всех покупок для телефона: 79034530417
✅ Обновлены статусы покупок для 1 уроков
```

## 4. Используйте новые инструменты отладки

### Для админов (долгое нажатие на карточку урока):
- **"Отладка покупки"** - показывает детальную информацию о статусе
- **"Принудительное обновление"** - обновляет статус конкретного урока
- **Кнопка 🔄** - обновляет статусы всех покупок

- Статусы локального состояния и Firebase
- Легко найти где произошла ошибка

## 🚨 Частые проблемы:

### 1. Неправильный номер телефона
- Проверьте `UserDefaults.standard.string(forKey: "userPhone")`
- Должен совпадать с записью в Firebase

### 2. Неправильный ID урока
- Проверьте описание платежа в webhook
- Формат: `"Оплата в BalanceApp: Урок (телефон: +79001234567, ID: lesson_6)"`

### 3. Проблемы с Firebase
- Проверьте правила безопасности
- Проверьте подключение к интернету

### 4. Проблемы с webhook
- Проверьте доступность URL
- Проверьте настройки в YooKassa
- Проверьте логи сервера

### 5. Проблемы с UI обновлением
- Используйте `objectWillChange.send()`
- Проверьте, что обновления происходят в `DispatchQueue.main.async`
- Используйте принудительное обновление
