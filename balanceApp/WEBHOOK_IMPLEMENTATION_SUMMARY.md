## 🔄 Как теперь работает система:

### **Основной поток (Webhook):**
1. **Пользователь оплачивает** → YooKassa обрабатывает платеж
2. **YooKassa отправляет webhook** → сервер получает уведомление
3. **Сервер создает покупку** → запись в Firebase
4. **iOS проверяет Firebase** → находит покупку и разблокирует урок

### **Резервный поток (iOS проверка):**
1. **iOS проверяет Firebase** → ищет существующую покупку
2. **Если покупки нет** → делает запрос к YooKassa API
3. **Максимум 10 попыток** → каждые 10 секунд
4. **Если webhook не сработал** → iOS создает покупку самостоятельно

## 📊 Преимущества новой системы:

- ✅ **Мгновенные уведомления** - webhook приходит за 1-5 секунд
- ✅ **Меньше нагрузки** - нет постоянных запросов от iOS
- ✅ **Надежность** - работает даже если пользователь закрыл приложение
- ✅ **Нет дубликатов** - проверка Firebase перед созданием
- ✅ **Резервная система** - iOS проверяет статус если webhook не сработал
