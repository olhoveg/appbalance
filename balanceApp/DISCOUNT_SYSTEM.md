# 🎯 Система скидок и акций для видео уроков

## 📋 Обзор

Система позволяет админам создавать временные акции со скидками на определенные видео уроки. Скидки автоматически применяются и отображаются пользователям в красивом виде.

## 🏗️ Архитектура

### Модель данных

```swift
struct Discount: Codable {
    let percentage: Int        // Процент скидки (например, 20 = 20%)
    let startDate: Date        // Дата начала акции
    let endDate: Date          // Дата окончания акции
    let isActive: Bool         // Активна ли скидка
}

struct VideoLesson: Identifiable, Codable {
    // ... основные поля
    var discount: Discount?    // Опциональная скидка
}
```

### Вычисляемые свойства

```swift
extension VideoLesson {
    var currentPrice: Int          // Текущая цена с учетом скидки
    var hasActiveDiscount: Bool    // Есть ли активная скидка
    var discountPercentage: Int?   // Процент скидки
    var originalPrice: Int         // Оригинальная цена
}
```

## 🎨 Отображение скидок

### В карточке видео урока

1. **На превью видео:**
   - Красный бейдж с процентом скидки в правом верхнем углу
   - Пример: `-20%`

2. **В секции цены:**
   - Зачеркнутая оригинальная цена
   - Красная цена со скидкой
   - Бейдж с процентом скидки
   - Пример: `~~1500 ₽~~` `1200 ₽` `-20%`

### В админском интерфейсе

- Отображение скидок в списке уроков
- Возможность быстрого удаления скидки через контекстное меню
- Предварительный просмотр цены при создании скидки

## 🔧 Админские функции

### 1. Создание скидки

```swift
// В VideoLessonEditView
let discount = Discount(
    percentage: 20,
    startDate: Date(),
    endDate: Date().addingTimeInterval(7 * 24 * 60 * 60), // +7 дней
    isActive: true
)
```

### 2. Управление скидками

- **Добавление:** `addDiscountToLesson(lessonId:discount:completion:)`
- **Обновление:** `updateDiscountForLesson(lessonId:discount:completion:)`
- **Удаление:** `removeDiscountFromLesson(lessonId:completion:)`

### 3. Интерфейс редактирования

- Переключатель "Добавить скидку"
- Поле для процента скидки
- Выбор дат начала и окончания
- Предварительный просмотр цены
- Переключатель активности скидки

## ⚡ Автоматизация

### Проверка активности скидки

```swift
var isCurrentlyActive: Bool {
    let now = Date()
    return isActive && now >= startDate && now <= endDate
}
```

### Вычисление цены со скидкой

```swift
func discountedPrice(from originalPrice: Int) -> Int {
    let discountAmount = originalPrice * percentage / 100
    return max(originalPrice - discountAmount, 0)
}
```

## 🎯 Сценарии использования

### 1. Сезонные акции
- **Черная пятница:** Скидка 30% на все уроки
- **Новый год:** Скидка 25% на уроки по релаксации
- **День массажиста:** Скидка 20% на профессиональные техники

### 2. Продвижение новых уроков
- Скидка 15% на новые уроки в первые 7 дней
- Скидка 10% на уроки определенного инструктора

### 3. Стимулирование покупок
- Скидка 5% при покупке 3+ уроков
- Скидка 10% для постоянных клиентов

## 🔒 Безопасность

### Валидация данных
- Процент скидки: 1-99%
- Дата окончания > дата начала
- Цена со скидкой > 0

### Права доступа
- Только админы могут создавать/редактировать скидки
- Пользователи видят только активные скидки
- Автоматическое отключение по истечении срока
