# Настройка Webhook для YooKassa

## 🎯 Зачем нужен Webhook?

Webhook позволяет YooKassa автоматически уведомлять ваш сервер о статусе платежей, что избавляет от необходимости постоянных запросов от iOS приложения.

## ✅ Преимущества Webhook:

- **Мгновенные уведомления** - статус платежа приходит сразу
- **Меньше нагрузки** - нет постоянных запросов от iOS
- **Надежность** - работает даже если пользователь закрыл приложение
- **Автоматическое создание покупок** - покупка создается сразу при успешной оплате

### 3. Проверьте настройки
- Убедитесь, что webhook активен
- Проверьте, что URL доступен из интернета

## 🔄 Как это работает:

### При успешной оплате:
1. **Пользователь оплачивает** → YooKassa обрабатывает платеж
2. **YooKassa отправляет webhook** → ваш сервер получает уведомление
3. **Сервер создает покупку** → запись добавляется в Firebase
4. **iOS проверяет Firebase** → находит покупку и разблокирует урок

### При ошибке:
1. **iOS делает резервную проверку** → запрашивает статус у YooKassa
2. **Максимум 10 попыток** → каждые 10 секунд
3. **Если webhook не сработал** → iOS создает покупку самостоятельно

## 🚨 Возможные проблемы:

### Webhook не приходит:
- Проверьте URL в настройках YooKassa
- Убедитесь, что сервер доступен
- Проверьте логи сервера

### Дублирование покупок:
- iOS проверяет Firebase перед созданием покупки
- Webhook и iOS не создают дубликаты

### Задержки:
- Webhook приходит в течение 1-5 секунд
- iOS делает резервную проверку через 10 секунд

## 🔧 Тестирование:

1. **Сделайте тестовую оплату**
2. **Проверьте логи сервера** - должно быть сообщение о webhook
3. **Проверьте Firebase** - должна появиться покупка
4. **Проверьте iOS** - урок должен разблокироваться

## 📝 Примечания:

- Webhook работает только с реальными платежами
- Тестовые платежи не отправляют webhook
- При отключении интернета iOS делает резервную проверку
- Все покупки сохраняются в Firebase под номером телефона пользователя
