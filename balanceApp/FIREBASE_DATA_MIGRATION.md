# Миграция данных из моков в Firebase

## Что изменилось

### ✅ Система теперь работает с реальными данными из Firebase:
- Убраны статичные моковые данные
- Все данные загружаются из Firebase Realtime Database
- Покупки сохраняются и проверяются в реальном времени

## Как загрузить тестовые данные в Firebase

### 1. Используйте FirebaseDataLoader
Создан специальный интерфейс для загрузки тестовых данных:

```swift
// Откройте FirebaseDataLoader в приложении
// Нажмите "Загрузить тестовые данные"
// Система автоматически загрузит 8 видео уроков
```

### 2. Что загружается:
- **8 видео уроков** с разными категориями
- **Разные инструкторы** (массажисты)
- **Разные цены** и длительности
- **Тестовые видео URL** и превью

### 3. Структура загружаемых данных:
```json
{
  "videoLessons": {
    "lesson_1": {
      "title": "Основы массажа спины",
      "instructor": "Анна Петрова",
      "category": "Массаж",
      "price": 1500,
      "duration": 1800
    },
    "lesson_2": {
      "title": "Техника глубокого массажа",
      "instructor": "Михаил Соколов",
      "category": "Массаж",
      "price": 2500,
      "duration": 2400
    }
    // ... и так далее
  }

```

## Пошаговая инструкция

### Шаг 1: Настройте Firebase
1. Убедитесь, что Firebase настроен согласно `FIREBASE_SETUP_VIDEO_LESSONS.md`
2. Проверьте подключение к Firebase в приложении

### Шаг 2: Загрузите тестовые данные
1. Запустите приложение
2. Откройте `FirebaseDataLoader` (можно добавить в навигацию)
3. Нажмите "Загрузить тестовые данные"
4. Дождитесь завершения загрузки (8 уроков)

### Шаг 3: Добавьте тестового админа
1. В том же интерфейсе нажмите "Добавить тестового админа"
2. Используйте номер телефона: `79001234567`

### Шаг 4: Протестируйте систему
1. Перейдите на вкладку "Видео уроки"
2. Увидите загруженные уроки из Firebase
3. Попробуйте поиск и фильтрацию
4. Протестируйте покупки

## Как добавить FirebaseDataLoader в навигацию

### Вариант 1: Временная кнопка в профиле
```swift
// В ProfileView.swift добавьте кнопку:
Button("Загрузить тестовые данные") {
    // Показать FirebaseDataLoader
}
```

### Вариант 2: Отдельная вкладка (для разработки)
```swift
// В ContentView.swift добавьте вкладку:
FirebaseDataLoader()
    .tabItem {
        Image(systemName: "cloud.upload")
        Text("Загрузка данных")
    }
    .tag(Tab.dataLoader)
```

## Проверка работы

### 1. Проверьте Firebase Console:
1. Откройте [Firebase Console](https://console.firebase.google.com)
2. Выберите ваш проект
3. Перейдите в Realtime Database
4. Убедитесь, что данные загружены в `videoLessons`

### 2. Проверьте в приложении:
1. Запустите приложение
2. Перейдите на "Видео уроки"
3. Увидите загруженные уроки
4. Попробуйте купить урок
5. Проверьте раздел "Мои видео уроки"

### 3. Проверьте админские функции:
1. Войдите с номером телефона админа (`79001234567`)
2. Увидите кнопку "+" в правом нижнем углу
3. Попробуйте добавить новый урок

## Возможные проблемы

### Если данные не загружаются:
1. Проверьте подключение к интернету
2. Убедитесь, что Firebase настроен правильно
3. Проверьте правила безопасности Firebase
4. Посмотрите консоль на наличие ошибок

### Если покупки не работают:
1. Проверьте, что пользователь авторизован
2. Убедитесь, что номер телефона сохранен в UserDefaults
3. Проверьте правила безопасности для `videoLessonPurchases`

## Следующие шаги

После успешной загрузки тестовых данных:

1. **Замените тестовые видео** на реальные файлы
2. **Обновите превью** на реальные изображения
3. **Добавьте реальных админов** вместо тестового
4. **Настройте VK Cloud** для хранения файлов
5. **Протестируйте все функции** с реальными данными

## Удаление тестовых данных

Если нужно очистить все данные:
1. Откройте `FirebaseDataLoader`
2. Нажмите "Очистить все данные"
3. Или удалите данные вручную через Firebase Console
