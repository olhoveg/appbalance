# Видео уроки - Полноценная система с Firebase и админским интерфейсом

## Описание
Реализована полноценная система видео уроков с интеграцией Firebase, админским интерфейсом и идентификацией через yclients. Система включает:

### Для пользователей:
- Просмотр доступных видео уроков
- Покупка отдельных видео уроков
- Просмотр купленных видео уроков
- Поиск и фильтрация по категориям
- Доступ к видео урокам через профиль

### Для админов:
- Добавление новых видео уроков
- Редактирование существующих уроков
- Управление статусом уроков (активен/неактивен)
- Удаление видео уроков
- Загрузка видео и превью в VK Cloud

## Структура файлов

### Основные файлы:
- `VideoLesson.swift` - Модель данных для видео урока (обновлена для Firebase)
- `VideoLessonPurchase.swift` - Модель для хранения покупок видео уроков
- `VideoLessonViewModel.swift` - ViewModel для управления видео уроками (Firebase + админские функции)
- `VideoLessonsView.swift` - Основное представление для видео уроков
- `VideoLessonCardView.swift` - Карточка отдельного видео урока
- `PurchasedVideoLessonsView.swift` - Представление купленных видео уроков
- `VideoLessonAdminView.swift` - Админский интерфейс для управления видео уроками
- `FirebaseDataLoader.swift` - Интерфейс для загрузки тестовых данных в Firebase
- `FIREBASE_SETUP_VIDEO_LESSONS.md` - Подробные инструкции по настройке Firebase
- `FIREBASE_DATA_MIGRATION.md` - Инструкция по миграции данных из моков в Firebase

### Интеграция:
- `ContentView.swift` - Добавлена новая вкладка "Видео уроки"
- `ProfileView.swift` - Добавлен раздел "Мои видео уроки" и кнопка загрузки тестовых данных

## Функциональность

### 1. Основной экран видео уроков (`VideoLessonsView`)
- Поиск по названию, описанию и инструктору
- Фильтрация по категориям
- Сетка карточек видео уроков
- Индикаторы загрузки и пустого состояния

### 2. Карточка видео урока (`VideoLessonCardView`)
- Превью видео (с поддержкой AsyncImage)
- Информация о видео (название, описание, инструктор, категория)
- Длительность видео
- Цена и кнопка покупки/просмотра
- Индикатор статуса покупки

### 3. Видео плеер (`VideoPlayerView`)
- Полноэкранный просмотр видео
- Использует AVKit для воспроизведения
- Автоматическое воспроизведение при открытии

### 4. Купленные видео уроки (`PurchasedVideoLessonsView`)
- Список всех купленных видео уроков
- Быстрый доступ к просмотру
- Информация о дате покупки

## Firebase интеграция

### Структура базы данных:
- **videoLessons** - коллекция видео уроков
- **videoLessonPurchases** - коллекция покупок пользователей
- **adminPhones** - список номеров телефонов админов

### Настройка Firebase:
1. Следуйте инструкциям в `FIREBASE_SETUP_VIDEO_LESSONS.md`
2. Настройте правила безопасности Firebase
3. Добавьте админов через Firebase Console или программно
4. Настройте VK Cloud для хранения видео файлов

### Интеграция с yclients:
- Идентификация пользователей по номеру телефона
- Проверка авторизации через yclients API
- Синхронизация данных пользователей

## Админские функции

### Доступ к админскому интерфейсу:
- Админы определяются по номеру телефона в Firebase
- Кнопка "+" появляется в правом нижнем углу экрана видео уроков
- Контекстное меню на карточках видео уроков для быстрых действий

### Возможности админов:
1. **Добавление видео уроков**:
   - Загрузка видео файлов в VK Cloud
   - Добавление превью изображений
   - Установка цены, категории, инструктора
   - Настройка длительности

2. **Управление уроками**:
   - Активация/деактивация уроков
   - Редактирование информации
   - Удаление уроков

3. **Мониторинг**:
   - Просмотр статистики покупок
   - Аналитика через AppMetrica

4. **Проверьте админские функции**:

## Безопасность

### Видео контент:
- Видео URL должны быть защищены (HTTPS)
- Рекомендуется использовать CDN для быстрой загрузки
- Возможно добавление DRM защиты для премиум контента

### Покупки:
- Текущая реализация использует простой API вызов
- Для продакшена рекомендуется интеграция с платежными системами
- Добавить валидацию покупок на сервере

## Устранение неполадок

### Частые проблемы:
1. **Видео не воспроизводится**: Проверьте URL видео и доступность
2. **Превью не загружается**: Проверьте URL превью и интернет соединение
3. **Покупка не проходит**: Проверьте API endpoint и формат данных
4. **Медленная загрузка**: Используйте CDN для видео и изображений

### Отладка:
- Включите логирование в `VideoLessonViewModel`
- Проверьте консоль на наличие ошибок сети
- Убедитесь, что все URL доступны и корректны
