# 🚀 Быстрый старт: Система видео уроков

## Что нужно сделать для запуска

### 1. ✅ Настройте Firebase
- Следуйте инструкции в `FIREBASE_SETUP_VIDEO_LESSONS.md`
- Убедитесь, что Firebase подключен к приложению

### 2. ✅ Загрузите тестовые данные
1. Запустите приложение
2. Перейдите в **Профиль**
3. Нажмите кнопку **"Загрузить тестовые данные"** (оранжевая кнопка)
4. Дождитесь загрузки 8 видео уроков
5. Нажмите **"Добавить тестового админа"**

### 3. ✅ Протестируйте систему
1. Перейдите на вкладку **"Видео уроки"**
2. Увидите загруженные уроки из Firebase
3. Попробуйте поиск и фильтрацию
4. Протестируйте покупки

## 📱 Что получится

### Для пользователей:
- **8 видео уроков** с разными категориями
- **Поиск** по названию, описанию, инструктору
- **Фильтрация** по категориям
- **Покупка** видео уроков
- **Просмотр** купленных уроков

### Для админов (номер: 79001234567):
- **Кнопка "+"** в правом нижнем углу
- **Добавление** новых видео уроков
- **Редактирование** существующих уроков
- **Удаление** уроков
- **Активация/деактивация** уроков

## ❓ Возможные проблемы

### Данные не загружаются:
- Проверьте интернет соединение
- Убедитесь, что Firebase настроен правильно
- Проверьте правила безопасности Firebase

### Покупки не работают:
- Проверьте авторизацию пользователя
- Убедитесь, что номер телефона сохранен
- Проверьте правила безопасности для покупок
